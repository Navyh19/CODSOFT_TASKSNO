## 🛠️ Tasks Completed

### 🎮 Task 1: Number Guessing Game
A simple console-based game where the program generates a random number and prompts the user to guess it. It provides instant feedback indicating whether the guess is "too high" or "too low" until the correct number is found.

### 🧮 Task 2: Simple Calculator
A utility that performs basic arithmetic operations, including addition, subtraction, multiplication, and division. The user provides two numbers and selects the desired arithmetic operator.

### ❌ Task 3: Tic-Tac-Toe Game
A console-based, two-player game mapped onto a 3x3 grid layout. Features include:
- Alternating turns between "X" and "O"
- Automated checks for a win or a draw
- An interactive option to restart and play another round

### 📝 Task 4: To-Do List Manager
A console-driven program designed to manage daily responsibilities. It enables users to:
- Input and add new items to the tracking list
- View tasks alongside their current status (Pending or Completed)
- Modify tasks by marking them as finished
- Remove unwanted items from the tracking view
